# Metron Diet - Desktop — εφαρμογή για Windows

Το εργαλείο του διατροφολόγου για υπολογιστή Windows: πελάτες, ραντεβού, μετρήσεις, διατροφή, PDF για τον πελάτη. Δίδυμο του Μέτρον για Android.

**Κατάσταση: σε ανάπτυξη. Δεν υπάρχει ακόμα διαθέσιμη έκδοση για λήψη.**

Όταν βγει η πρώτη έκδοση, εδώ θα βρεις τον σύνδεσμο λήψης και οδηγίες εγκατάστασης.

Τα δεδομένα σου θα μένουν μόνο στον υπολογιστή σου. Η εφαρμογή παρέχεται ως έχει, χωρίς εγγύηση.
